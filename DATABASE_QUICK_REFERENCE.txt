================================================================================
                          MAIN TABLES (4 TABLES)
================================================================================

1. COMPANIES TABLE
   ├─ company_name (TEXT) ............ Company name
   ├─ company_logo (URL) ............ Company logo URL
   └─ Stores: Company information
   
   Example: Adani Power, TCS, Reliance Industries

2. IPOs TABLE (⭐ MAIN DATA - STOCK PRICES HERE)
   ├─ company_id (FK) ............... Links to company
   ├─ price_band (TEXT) ............. Price range (e.g., 329-136)
   ├─ open_date (DATE) .............. When IPO opens
   ├─ close_date (DATE) ............. When IPO closes
   ├─ issue_size (TEXT) ............. Issue size (e.g., 4530 Cr)
   ├─ issue_type (TEXT) ............. Type (e.g., Book Built)
   ├─ listing_date (DATE) ........... Listing date
   ├─ status (VARCHAR) .............. Upcoming/Open/Closed/Listed
   ├─ ipo_price (DECIMAL) ........... IPO PRICE (STOCK PRICE 1)
   ├─ listing_price (DECIMAL) ....... LISTING PRICE (STOCK PRICE 2)
   ├─ listing_gain (DECIMAL) ........ Listing gain % (STOCK PRICE 4)
   ├─ current_market_price (DECIMAL)  CURRENT PRICE CMP (STOCK PRICE 3)
   └─ current_return (DECIMAL) ...... Current return %
   
   Stores: All IPO details and stock price information

3. DOCUMENTS TABLE
   ├─ ipo_id (FK) .................. Links to IPO
   ├─ rhp_pdf (URL) ................ RHP PDF link
   └─ drhp_pdf (URL) ............... DRHP PDF link
   
   Stores: Document/PDF links for each IPO

4. APPLICATIONS TABLE
   ├─ user_id (FK) ................. User who applied
   ├─ ipo_id (FK) .................. IPO applied for
   ├─ quantity (INT) ............... Number of shares
   └─ status (VARCHAR) ............. Application status
   
   Stores: User IPO applications

================================================================================
                    DJANGO BUILT-IN TABLES (FOR AUTH)
================================================================================

5. auth_user TABLE
   ├─ username (TEXT) .............. Login username
   ├─ password (HASHED) ............ Encrypted password
   ├─ email (TEXT) ................. User email
   ├─ is_staff (BOOLEAN) ........... Is admin? Yes/No
   ├─ is_active (BOOLEAN) .......... Active account? Yes/No
   └─ date_joined (DATETIME) ....... Registration date
   
   Stores: User accounts and authentication

6. Other Django Tables (Session, Permission, etc.)
   └─ Used by Django framework

================================================================================
                        STOCK PRICE DATA LOCATION
================================================================================

WHERE IS STOCK DATA STORED?
===========================

In 'ipos' table, these columns store STOCK PRICES:

  1. ipo_price
     └─ Initial offering price
     └─ Example: ₹383

  2. listing_price
     └─ Price on listing day
     └─ Example: ₹435

  3. current_market_price
     └─ Current trading price (CMP)
     └─ Example: ₹410

  4. listing_gain
     └─ % gain from IPO to listing
     └─ Example: 13.58%

  5. current_return
     └─ % return from IPO to now
     └─ Example: 7.05%

WHERE IS LIVE MARKET DATA?
===========================

API Endpoint: /api/v1/stock/
   └─ Fetches LIVE data from NSE (National Stock Exchange)
   └─ Returns: 52-week high/low prices
   └─ NOT stored in database
   └─ Fetched in real-time via nselib library

================================================================================
                    QUICK QUERY EXAMPLES
================================================================================

Get all IPOs with prices:
  SELECT company.company_name, ipo.ipo_price, ipo.current_market_price
  FROM ipos
  JOIN companies ON ipos.company_id = companies.id;

Get IPOs by status:
  SELECT * FROM ipos WHERE status = 'Listed';

Get user applications:
  SELECT auth_user.username, ipos.company.company_name, applications.quantity
  FROM applications
  JOIN auth_user ON applications.user_id = auth_user.id
  JOIN ipos ON applications.ipo_id = ipos.id;

Get all documents:
  SELECT ipos.company.company_name, documents.rhp_pdf, documents.drhp_pdf
  FROM documents
  JOIN ipos ON documents.ipo_id = ipos.id;
