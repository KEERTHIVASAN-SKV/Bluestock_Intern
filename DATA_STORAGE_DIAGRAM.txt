================================================================================
                    COMPLETE DATA CYCLE
================================================================================

1. INPUT:
   Admin enters data in web form
   └─ Company name, IPO details, stock prices

2. VALIDATION:
   Django validates the data
   └─ Check dates are correct
   └─ Check prices are valid decimals

3. STORAGE:
   Data stored in PostgreSQL
   └─ companies table
   └─ ipos table (with all stock prices)
   └─ documents table (PDF links)

4. RETRIEVAL:
   User requests data via API
   └─ GET /api/v1/ipos/

5. DISPLAY:
   Response shows all data:
   {
     "company_name": "Adani Power",
     "ipo_price": 383.00,
     "listing_price": 435.00,
     "current_market_price": 410.00,
     "listing_gain": 13.58,
     "current_return": 7.05
   }

6. UPDATE:
   Admin modifies IPO (e.g., update current price)
   └─ Changed in database
   └─ Reflected in API response

7. DELETE:
   Admin deletes IPO (if needed)
   └─ Cascade deletes documents and applications
   └─ Data removed from database
