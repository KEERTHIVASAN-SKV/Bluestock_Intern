================================================================================
API ENDPOINTS REFERENCE
================================================================================

Authentication:
- POST /api/token/ → Login (returns JWT tokens)
- POST /api/token/refresh/ → Refresh expired token
- POST /api/v1/register/ → Sign up (public, no auth)

IPO Management:
- GET /api/v1/ipos/ → Get all IPOs (public)
- POST /api/v1/ipos/ → Create IPO (admin only, JWT required)
- PUT /api/v1/ipos/{id}/ → Update IPO (admin only, JWT required)
- DELETE /api/v1/ipos/{id}/ → Delete IPO (admin only, JWT required)

Companies:
- GET /api/v1/companies/ → List companies (public)
- POST /api/v1/companies/ → Create (admin only)
- PUT /api/v1/companies/{id}/ → Update (admin only)
- DELETE /api/v1/companies/{id}/ → Delete (admin only)
