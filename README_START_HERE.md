## 🎯 WHAT IS THIS PROJECT?

The **Bluestock IPO Portal** is a full-stack web application for tracking and managing Initial Public Offerings (IPOs) in the Indian stock market. Users can:
- Browse upcoming, ongoing, and listed IPOs
- Track stock prices in real-time
- Create watchlists
- Access market analysis
- Admins can manage IPO data

**Tech Stack**: Django + React + PostgreSQL + NSE API
